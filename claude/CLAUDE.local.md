# 個人的な作業ルール（git には含めない）

`age_inference_from_xp_spectra` と `astroNN_stars_foundation` での作業に共通のルール（同じ内容を両方に置いている）。

## 実行の前に提案して OK をもらう

- スクリプトの作成・実行、ファイルの移動、計算の前に、ディレクトリ・ファイル名・手順・出力（図・ログ）を提案し、OK をもらってから始める。
- 順番が決まっていても、それは実行の OK ではない。

## コミットメッセージ

- コミットメッセージはユーザーが書く。もらったものを使い、本文や Co-Authored-By などの行は付けない。
- タイポや文法の誤りがあれば直した案を示し、OK をもらってから commit する。
- メッセージをもらっていなければ、commit の前に聞く。

## サーバーのパスを公開しない

- サーバーの絶対パス（メモリの `server-current.md` に書いた `<WORK>` の実際の値）を、GitHub に push するファイル（コード・README・ログ）に入れない。
- ログや md のパスは `<WORKDIR>` などに置き換え、push の前にそのパスで grep して確かめる。

## Notion の文は節ごとに確認してから直す

- 結果のページの文（結果の説明・言えること）を直すときは、節ごとに「今の文 → 案」を示し、OK をもらってから書き込む。
- 図や表の差し替えだけなら、文は変えずに先に行ってよい。文の意味が変わる場合は報告して相談する。
